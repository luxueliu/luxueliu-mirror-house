# 设计笔记（剧透）

> 这一页有三关的答案和证明。想自己玩，先别读。

## 第一关：自描述数

定义：L 位数 d0..d(L-1)，第 i 位等于数字 i 在整串里出现的次数。

十位以内，七个：

```
1210
2020
21200
3211000
42101000
521001000
6210001000
```

为什么只有这些：各位数字之和恰好等于 L。若某个位置上的数字大于等于 L，这一位就要求「数字 j 的个数」至少是 L；总共只有 L 位，于是所有位都得是 j——若 j 非 0，「0 的个数」对不上第一位；若 j 是 0，最高位又不能是 0。所以所有数字都小于 L，各位之和正好是 L。

搜索用「和为 L 的计数向量」而不是 10^L 个数；10 位也只有 92368 种。

## 第三关：十格映射的两个循环

十格描述 T(n)：数 0..9 的个数，拼成十位（前导零也算一格）。

在「十格、各位和 10、每位不超过 9」的 92368 个状态里，所有轨道只通向两个循环：

```
1-循环   6210001000
2-循环   6300000100 -> 7101001000 -> 6300000100
```

2026 的轨道：

```
2026 -> 1020001000 -> 7210000000 -> 7110000100 -> 6300000100 -> 7101001000 -> ...
```

四个箭头进循环，然后二循环。第三关的答案是 `6300000100` 和 `7101001000`，顺序不限。

十个数字全同的十位数（1111111111 等）计数会出现 10，撑破十格；单独追过，七步之后也落进二循环。

## 第二关：回文池

题目从七条流传的回文里抽一条当参考答案，再抽两个字当必用字、一个字当禁用字。所以每道题至少有一个解。

判卷规则：长度精确、只收汉字、正读倒读相同、必用字都在、禁用字不在、不同汉字至少 4 个。

## 计分

每题得分 = 基础分 - 10 × 错次 - 提示单价 × 提示条数，最低 0。满分 500。
